# Support

## Project status

This is an independently maintained open-source project. It is not a Microsoft
product or service, and it is not part of the official Azure Landing Zones
Accelerator.

The primary maintainer is a Microsoft employee, but maintains this project in
an individual capacity. That employment does not create Microsoft sponsorship,
ownership, endorsement, support, or an obligation to maintain this project.
Microsoft and Azure names, product names, and publicly permitted branding are
used only to identify the technologies that the project integrates with.

## How to file issues and get help

This project uses [GitHub Issues](https://docs.github.com/en/issues) to track bugs and
feature requests. Please search the existing issues before filing new ones to avoid
duplicates. For new issues, file your bug or feature request as a new issue.

For help and questions about using this project, please:

- Use the [documentation index](docs/README.md) for operator, consumer, and component references.
- Start with [`QUICKSTART.md`](QUICKSTART.md) for a day-1 walkthrough.
- Open a [GitHub Discussion](https://docs.github.com/en/discussions) (if enabled) or a
  GitHub Issue for questions not covered by the docs.

## Support policy

This is a community-supported, open-source accelerator. Support is limited to the
resources listed above and provided on a best-effort basis by the maintainers and
community. It is **not** covered by any commercial support agreement, SLA, or
Azure support plan.

You can expect:

- Public documentation and examples that describe the intended behavior.
- Public issue tracking for reproducible defects and enhancement requests.
- Community responses when maintainers or contributors have time and relevant
  knowledge.
- Security-reporting instructions in [`SECURITY.md`](SECURITY.md).

You must not expect:

- A guaranteed response or resolution time.
- An uptime, availability, maintenance, or compatibility SLA.
- On-call assistance, operational monitoring, incident response, or
  production troubleshooting.
- Microsoft Support to diagnose, repair, or maintain this accelerator.
- Microsoft to accept responsibility for deployments created with this
  accelerator.
- Continued development, specific features, release dates, or support for
  every Azure configuration.

Your organization remains responsible for reviewing the source, testing
changes, securing the delivery environment, approving deployments, operating
the generated vending service, and validating that the result meets its
security, compliance, reliability, and support requirements.

## Microsoft and Azure support boundary

Your existing Microsoft or Azure support agreement continues to apply to the
underlying Microsoft products and Azure services according to its own terms.
It does not extend support coverage to this accelerator, its generated
repositories, custom workflows, configuration, or deployment decisions.

When an issue appears to originate in an Azure service, an official Microsoft
tool, or an Azure Verified Module, you may need to reproduce the issue outside
this accelerator and report it through the support channel for that product.
The maintainers may help identify the likely boundary, but they cannot make a
support determination on Microsoft's behalf.

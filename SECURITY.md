# Security Policy

## Reporting a Vulnerability

Please do **not** use public GitHub issues, discussions, or pull requests for
security reports.

For suspected vulnerabilities, use **GitHub Private Vulnerability Reporting**
via the repository's **Security** tab → **Report a vulnerability**.

## Please include

- A description of the vulnerability
- The affected area and versions, if known
- Reproduction steps or a proof of concept
- The expected impact
- A suggested remediation, if available

## Disclosure

Please allow reasonable time for investigation and remediation before any public
disclosure. Reports will be acknowledged as promptly as possible.

## Public channels

Please do not post undisclosed vulnerabilities in:

- GitHub Issues
- GitHub Discussions
- Pull Requests
